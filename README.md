# پابه‌پا | Pabepa

**هم‌تمرین پیدا کن. قرار تمرین بگذار.**

پابه‌پا یک وب‌اپ فارسی برای پیدا کردن همراه ورزشی است. اگر برای دویدن در محله، یک بازی بدمینتون یا تمرین گروهی دنبال همراه می‌گردی، می‌توانی زمان، مکان و سطح تمرین را مشخص کنی، آگهی‌های مرتبط را ببینی و هماهنگی را در پیام خصوصی ادامه بدهی.

> **وضعیت پروژه** · نسخهٔ وب در حال توسعه و آماده‌سازی برای بتای آنلاین است.

## از پیدا کردن همراه تا قرار تمرین

| قابلیت | تجربهٔ کاربر |
| --- | --- |
| **ثبت و جست‌وجوی آگهی** | آگهی را با رشته، سطح، شهر، محله، زمان و تعداد همراهان ثبت کن. جست‌وجو را با فیلترها، از جمله ترجیح جنسیت همراه، محدود کن. |
| **آگهی‌های مشابه** | پیشنهادهای مرتبط را ببین و گزینه‌های بیشتری برای تمرین پیدا کن. |
| **پروفایل ورزشی** | عکس، معرفی، رشته‌ها و سطح تمرینت را اضافه کن. ثبت قد و وزن برای نمایش در پروفایل عمومی اختیاری است. |
| **پیام خصوصی** | از آگهی یا پروفایل عمومی گفت‌وگو را شروع کن و جزئیات تمرین را هماهنگ کن. |
| **کارت استوری** | بعد از ثبت آگهی، کارت آن را برای انتشار در استوری اینستاگرام یا پلتفرم‌های دیگر به اشتراک بگذار. |
| **مدیریت آگهی‌های من** | آگهی‌های خودت را ببین و در صورت نیاز آن‌ها را ببند یا لغو کن. |

## زیرساخت پروژه

پابه‌پا یک مخزن چندبخشی با **pnpm workspaces** است. رابط وب فارسی و راست‌به‌چپ است و زمان قرارها با تقویم شمسی و به وقت تهران نمایش داده می‌شود.

| بخش | فناوری |
| --- | --- |
| وب · `apps/web` | Next.js App Router، React، TypeScript، Tailwind CSS |
| API · `apps/api` | NestJS، REST API |
| داده و مهاجرت‌ها | PostgreSQL، PostGIS، Drizzle ORM |

## مسیر توسعه

1. **ثبت نسخهٔ V0** برای ثبت وضعیت فعلی پروژه پیش از استقرار.
2. **راه‌اندازی بتای وب** و آزمون مسیر ثبت آگهی تا هماهنگی تمرین روی سرور، همراه با اتصال پیامک واقعی. ورود با کد یک‌بارمصرف در محیط توسعه پیاده‌سازی شده است.
3. **توسعهٔ اپ اندروید و iOS** پس از تأیید عملکرد مسیرهای اصلی API در محیط آزمایشی.

---

**Pabepa** is a Persian-language web app for finding workout partners. Create a listing, discover relevant training opportunities, and make plans through private messaging. The web app is in development, with an online beta and Android and iOS apps planned.
